# synth_pcb.pretty

Footprints for the circuit PCBs of my synth modules. The panel side of the same parts is in [`synth_panel.pretty`](../synth_panel.pretty).

| Footprint | Description |
| --- | --- |
| `2MD6T1B5M2RE` | DPDT toggle switch, 0.1 A / 20 V, solder pins ([datasheet](https://www.farnell.com/datasheets/3707472.pdf)) |
| `2MS1T1B5M2RE` | Toggle switch, 3 pins |
| `Alpha POT Original` | Alpha pot, PTV09A-4 |
| `M64Y102KB40` | Trimmer pot |
| `Jack_3.5mm_QingPu_WQP-PJ398SM_Vertical_CircularHoles_3d` | Thonkiconn 3.5 mm vertical jack with round holes |
| `IDC-Header_2x05_P2.54mm_Vertical-NoSign` | 2x05 IDC box header, 2.54 mm pitch, with no pin-1 marking |
| `LED_D3.0mm` | 3 mm through-hole LED |
